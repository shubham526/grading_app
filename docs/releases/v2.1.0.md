# v2.1.0 — Question-Centric Manual Grading

v2.1.0 adds a second manual grading workflow that lets instructors and TAs grade
one question across all students before moving to the next question.

## Added

- canonical criterion `question_id` metadata with backward-compatible inference;
- natural question ordering and `UNASSIGNED` handling;
- separate question-centric criterion grouping without changing legacy scoring groups;
- existing-assessment-folder and roster-CSV student lists;
- question and student navigation controls;
- criterion filtering by selected question;
- partial assessment saves merged by stable criterion ID;
- explicit grading status so an intentional zero is distinct from untouched work;
- per-question and overall criterion progress;
- optional per-student `grading_progress` navigation metadata;
- question completion markers;
- ID-based assessment loading with legacy title fallback.

## Preserved

- student-by-student grading remains the default;
- selected-question and best-N-of-M scoring behavior is unchanged;
- total score formulas are unchanged;
- ABET outcome/evidence calculations are unchanged;
- analytics and PDF scoring continue to consume the same assessment score fields.

## Not Included

This release does not add submission ingestion, LaTeX/PDF parsing, similarity
review, LLM grading/feedback, submission chat, OCR, plagiarism verdicts, or
semantic-similarity features. Those remain later-roadmap work.
